# Мафия — эмуляция на C++20

Учебный проект: программная эмуляция настольной игры «Мафия» с собственным `SharedPtr`, потоками/корутинами, файловыми логами, концептами, доп. ролями и YAML-конфигом.

## Требования

- C++20-компилятор (`clang++` или `g++`)
- `make`
- POSIX-потоки (`pthread`)

Внешние библиотеки не нужны (для будущей AI-части в `third_party/` лежит `json.hpp`, сейчас не используется).

## Сборка и проверки

```bash
make              # build/mafia и build/mafia_tests
make test         # юнит-тесты
make run          # пример игры
make asan         # AddressSanitizer + UndefinedBehaviorSanitizer
make tsan         # ThreadSanitizer + серия игр на потоках
make clean
```

## Запуск

```bash
./build/mafia [параметры]
```

### Основные параметры

| Параметр | Описание |
|---|---|
| `--players N`, `-n N` | Число игроков, N ≥ 5 (по умолчанию 10) |
| `--interactive` | Вы — Игрок1, остальные боты |
| `--open-announcements` | Открытые объявления (роль, кто кого убил, кого лечил Доктор) |
| `--closed-announcements` | Закрытые объявления: только сторона (по умолчанию) |
| `--full-log` | Полный лог: ночные ходы, голоса, проверки |

### Дополнительно

| Параметр | Описание |
|---|---|
| `--mafia-divisor k`, `-k k` | Мафии = max(1, ⌊N/k⌋), k ≥ 3 (по умолчанию 3) |
| `--seed S` | Зерно ГПСЧ (один seed — одна и та же игра) |
| `--engine thread\|coro\|seq` | Потоки (по умолчанию) / корутины / последовательно |
| `--config FILE` | YAML с особыми ролями (см. `config/roles.yaml`) |
| `--log-dir DIR` | Каталог логов (по умолчанию `logs`) |
| `--no-file-log` | Не писать логи в файлы |
| `--print-config` | Показать разобранные параметры и выйти |
| `--dump-roles` | Показать раздачу ролей и выйти |
| `--help`, `-h` | Справка |

Флаг `--ai` зарезервирован под будущий AI-агент и пока **не реализован**.

### Примеры

```bash
# Обычная партия ботов, открытые объявления
./build/mafia --players 10 --open-announcements

# Воспроизводимая игра на корутинах
./build/mafia --players 12 --seed 42 --engine coro --full-log

# С доп. ролями из YAML
./build/mafia --players 12 --seed 7 --config config/roles.yaml --dump-roles
./build/mafia --players 12 --seed 7 --config config/roles.yaml

# Интерактивно (вы — Игрок1)
./build/mafia --players 8 --interactive --seed 3 --engine seq

# Только параметры / раздача
./build/mafia --players 10 --print-config
./build/mafia --players 10 --seed 42 --dump-roles
```

При одинаковом `--seed` и одинаковых параметрах исход партии совпадает для `--engine seq`, `thread` и `coro`.

## Роли

**Базовые:** Мирный житель, Мафия, Комиссар, Доктор, Маньяк.

**Дополнительные** (через `--config`):

| Роль | Сторона | Ночь |
|---|---|---|
| Ниндзя | мафия (в квоте мафии) | Как мафия; Комиссару виден мирным |
| Телохранитель | мирные | Защищает цель; контрудар по мафии/маньяку; от Комиссара только спасает |
| Свидетель | мирные | Следит за игроком; при покушении узнаёт нападавшего |

Пример `config/roles.yaml`:

```yaml
mafia_divisor: 3
roles:
  - commissar
  - doctor
  - maniac
  - ninja
  - bodyguard
  - witness
```

Без `--config` раздаются Комиссар, Доктор и Маньяк (плюс мафия по формуле).

## Правила (кратко)

- Цикл: день (обсуждение + голосование) → ночь → проверка победы.
- **Голосование:** выбывает лидер по голосам; при ничьей никто не выбывает.
- **Доктор:** лечит ночью, не одного и того же дважды подряд, может себя.
- **Комиссар:** ночью либо проверяет, либо стреляет. Маньяк и Ниндзя при проверке видны мирными.
- **Мафия:** предлагает жертву; решение озвучивает Босс (первый живой мафиози).
- **Маньяк:** убивает каждую ночь; побеждает один на один с мирным (или один).
- **Мирные** побеждают, когда нет мафии и Маньяка.
- **Мафия** побеждает, когда её не меньше остальных *и* Маньяк уже мёртв.

## Движки ходов

| `--engine` | Как исполняются ходы |
|---|---|
| `thread` | Отдельный `std::thread` на игрока (базовый вариант задания) |
| `coro` | Корутины + свой планировщик |
| `seq` | Последовательно в одном потоке (удобно для отладки) |

Решения игрока отделены от механизма исполнения: `BotBrain` / `HumanBrain`.

## Логи

При включённых файловых логах создаётся каталог `logs/game_<дата-время>/`:

- `round_00.txt`, `round_01.txt`, … — события раундов
- `summary.txt` — победитель и сводка по игрокам
